## Proje Kapsamı ve Kritik Eşik Mantığı[span_8](start_span)[span_8](end_span)
Projemizin karar mekanizmalarında **KRİTİK EŞİK** sözde kod (pseudocode) mantığı şu şekilde metinsel olarak kurgulanmıştır:

> **Başla**
> 1. Kullanıcıdan bir işlem seçmesi istenir.
> 2. Eğer girilen değer veya işlem hacmi belirlenen **Kritik Eşik** sınırını aşarsa (Örn: İşlem süresi veya veri boyutu > Eşik Değeri):
>    * Uyarı mesajı gösterilir ("*Kritik eşik aşıldı! Güvenli moda geçiliyor.*")
>    * Sistem otomatik olarak yedekleme protokolünü çalıştırır.
> 3. Değilse, normal işlem akışına devam edilir.
> **Bitir**
